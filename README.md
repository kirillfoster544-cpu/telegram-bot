# GUARANT (Railway) — сайт + бот в одном сервисе

## Variables (Railway)
- BOT_TOKEN = токен бота
- ADMIN_ID = твой TG id (например 7489815425)
- APP_BASE_URL = публичный URL сервиса (например https://telegram-bot-production-6147.up.railway.app)
- COMMISSION_PCT = комиссия (например 0 или 5)
- DB_PATH = (не обязательно) путь к sqlite файлу, например /data/guarant.sqlite3

## Команды бота
- /start — кнопка 💎 Гарант (открывает мини-апп)
- /help — список команд
- /workbr TG_ID AMOUNT — (только админ) выдать баланс пользователю

## Как работает сделка
1) Создать сделку (описание/сумма/роль) → получить ссылку
2) Второй участник открывает ссылку → нажимает "Присоединиться"
3) Покупатель нажимает "Оплатить с баланса"
4) Продавец нажимает "Выполнено"
5) Покупатель нажимает "Подтвердить" → деньги продавцу на баланс
